# 갈대 Galdae

순천대 유학생을 위한 취미 기반 소모임 매칭 서비스

- 과목: 어드벤처디자인 01분반 (2026-2학기)
- 발표자: 인공지능학과 안가라그 (20244909)

## 문제
유학생은 늘고 있지만, 수업 밖에서 친구를 사귈 기회는 부족합니다.
큰 동아리는 부담스럽고, 오픈채팅은 신뢰가 낮습니다.

## 아이디어
취미 · 언어 · 시간이 맞는 3–6명 소모임을 추천합니다.
- 작게: 부담 없는 소모임
- 맞게: 추천 이유를 함께 보여 줌
- 안전하게: 학교 이메일 인증, 캠퍼스 공개 장소
